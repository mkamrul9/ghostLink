# Community code of conduct

Mystic welcomes people with different backgrounds and experience levels. Be respectful, patient and specific when discussing problems or changes.

- Critique ideas and code without insulting people.
- Help newcomers understand the project. Assume good intent and ask for clarification.
- Do not harass, threaten, discriminate, publish someone's private information, or use sexualized language or imagery.
- Do not post spam, private file contents, credentials or active room invitations.
- Respect maintainers' scope and review decisions; discuss disagreements constructively.

These expectations apply in issues, pull requests, discussions and other project spaces. Maintainers may edit or remove harmful content, close disruptive threads, or restrict participation. Repeated or serious abuse may result in a ban.

For a private report of abuse, use GitHub's **Report abuse** option on the relevant content or profile. For project-process concerns that can safely be public, contact maintainers through a repository discussion without repeating sensitive details. Security vulnerabilities follow [SECURITY.md](SECURITY.md).
